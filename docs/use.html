# Cooling checklist pilot — fictional teaching source

P1. This invented memo exists only to teach faithful extraction. No real organization, study or performance result is represented.

P2. During the first week, the workshop recorded 15 damaged units among 100 inspected units. During the second week, after introducing a cooling checklist, it recorded 12 damaged units among 100 inspected units. These were different batches, not repeated measurements of the same units.

P3. The second week also used a new supplier and fewer novice operators. There was no control group or randomized assignment. The memo cannot identify which change caused the difference.

P4. The difference is 3 percentage points in observed damage rate (15% to 12%), or a 20% relative reduction from the first week's rate. The memo does not provide uncertainty estimates or evidence of a sustained effect.

P5. The checklist is a candidate for a controlled follow-up, not an approved universal instruction. In the workshop's stated procedure, fragile glass units must not be cooled using this checklist until the separate glass protocol has been reviewed. The pilot used metal units only.

P6. A manager's slide repeats the same 15-to-12 comparison from this memo. The slide is not a second study. The memo contains no evidence about costs, other workshops or long-term failure rates.

Save a record

With Python 3.10 or later, run these one-line commands from the complete skill folder. Use a workspace outside the installation:

python scripts/yammerknit_tool.py init-record --source "SOURCE.txt" --workspace "WORKSPACE" --title "Source title"
python scripts/yammerknit_tool.py validate --artifact "DRAFT.md"
python scripts/yammerknit_tool.py store-artifact --artifact "DRAFT.md" --workspace "WORKSPACE" --record-id "RETURNED-ID"

Copy the ID returned by the first command. Source preservation is not artifact creation. A structural pass is not a source-fidelity review. Open the original locators and compare the consequential claims before reuse.

Browse, return and revise

Return without remembering a query or ID:

python scripts/yammerknit_tool.py inspect-record --workspace "WORKSPACE"

Browse titles, channels, record IDs, health and current artifact paths. A damaged neighbor remains visible as an error. Add --record-id "ID" to verify one complete chain and open its current artifact. current: null means no artifact has been stored. verified-present-bytes checks byte consistency, not source truth or authorship.

Work in a separate draft and use revise-artifact for a correction. Preserve the base and explain what changed. Changed source content belongs in a new source record. Copy the entire workspace to move it, then inspect at its new path. See integrity recovery if inspection fails.

Optional YouTube subtitles

The helper needs separately installed yt-dlp. Supply one credential-free video URL and one exact language code, such as en or en-US. Playlist and channel URLs are rejected. It requests subtitles without ambient cookies or audiovisual download, then checks video and language identity.

Raw VTT remains original evidence. Readable text retains start/end ranges, voice labels and repeated distinct cues. Manual versus automatic origin stays unknown unless separately established. A transcript cannot prove unseen visual content or caption accuracy. If acquisition fails, supply transcript text; there is no audio-download fallback.

Helper commands and success

python scripts/yammerknit_tool.py --help
python scripts/yammerknit_tool.py acquire-youtube --url "VIDEO-URL" --workspace "WORKSPACE" --languages "en"

Use an absolute script path if working elsewhere. Help performs no writes. New records return their ID and exact paths. Existing records are preserved on collision; source and artifact files are checked before a current artifact is named. A saved receipt describes the check actually performed, not a model trial.

Keep context when preparing for retrieval

Each reusable unit needs ordinary search terms, a scoped claim, origin type, source identity and locator, and the qualifier that changes the answer. Include hashes only when computed from actual bytes. Read the unit alone: can it answer the intended question without borrowing a missing exception from the executive summary?

For the pilot, “Does this prove a checklist effect in glass?” must yield no: causality is unresolved and glass was excluded. “How much money does it save?” is unknown. These questions test the actual misunderstanding; merely matching a topic does not.

Yammerknit prepares an inspectable representation. A separate pipeline must execute embedding and retrieval, and compare actual outcomes before claiming improvement. Glyphs, a persona and structural validity supply no such measurement.
