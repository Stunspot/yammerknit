Working guide

Use Yammerknit

Talk to the agent normally. Name a workspace only when you want durable source and revision records.

On this page

  • Create
  • Save a record
  • Inspect or repair
  • YouTube subtitles

Create a Yammerknit

Supply a transcript or document and ask for the complete artifact:

Turn this transcript into a Yammerknit.
Return the complete codefenced artifact.

Yammerknit preserves supplied metadata, marks missing metadata N/A, follows semantic gravity rather than transcript order, and includes the full cluster mesh, relational bridges, prompt seeds, and sigil lexicon.

Save an organized record

Turn this transcript into a Yammerknit.
Preserve the source and organize the result in <workspace>\Yammerknits.

The workspace keeps original source bytes, normalized UTF-8 text, the base artifact, later revisions, manifests, and validation receipts distinct.

To inspect a saved record without changing it:

python scripts/yammerknit_tool.py inspect-record
  --workspace <PATH>
  --record-id "<ID>"

Inspect or repair an artifact

Inspect this Yammerknit against the canonical SOP.
Explain every material defect.

For a repair:

Repair only the failed structure.
Preserve sound content and sigil order.
Save a new revision.

A repair creates a revision. It does not overwrite the original artifact.

Acquire public YouTube subtitles

The optional helper requires a separately installed yt-dlp:

python -m pip install -U yt-dlp

Then ask:

Acquire the subtitles from <YouTube URL>,
preserve them in <workspace>,
and create a Yammerknit.

The helper requests accessible subtitles without downloading audiovisual media, opening browser cookies, or traversing playlists. If subtitles are unavailable, provide transcript text directly.

Prepare for vector RAG

Yammerknits preserve semantically useful shards, relationships, sigils, and provenance before embedding. The artifact becomes part of an operating vector-RAG system only after a separate embedding and vector-storage pipeline ingests it.

No sleight of hand: Yammerknit does not include a vector store, embedding model, ingestion service, or retrieval execution.
