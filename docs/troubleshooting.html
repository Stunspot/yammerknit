Troubleshoot Yammerknit

Start from what you can observe. Preserve the source before changing a record.

Symptoms

  • Codex not installed
  • Claude cannot find it
  • Python or helper unavailable
  • yt-dlp unavailable
  • No subtitles
  • Validation fails
  • Overwrite refused
  • Stale paths

Codex cannot find the plugin

Follow the included marketplace route. Check codex plugin marketplace list and codex plugin list. The marketplace root must contain this kit's codex-plugin/yammerknit/.codex-plugin/plugin.json. Start a fresh task after installation.

Claude cannot find the skill

Confirm the installed path ends in yammerknit/SKILL.md. An extra directory level prevents discovery. Restart the host when the skills directory was created after the current session began.

Python or the helper script is unavailable

Core inline artifact creation can continue without Python. Persistence, validation, revision, inspection, and subtitle acquisition require Python and the complete skill folder. Run commands from that folder or use its absolute scripts/yammerknit_tool.py path; do not invoke a similarly named script from an old extracted kit.

yt-dlp is unavailable

Supply transcript text, or install the optional backend through your normal environment process, for example python -m pip install yt-dlp. Installing Yammerknit does not automatically upgrade dependencies. Backend errors withhold raw logs that may contain private data; inspect those separately only when needed.

No VTT subtitles were available

The video may have no accessible human or automatic subtitles. Provide an authorized transcript or another source document. The helper does not fall back to downloading or transcribing audio.

The artifact fails structure or source fidelity

Read the validator's named errors and correct those fields in a separate draft. Compare consequential claims with the actual source, including limits and conflicting passages. A structural pass cannot settle semantic fidelity. Save a verified correction as a revision; retain the base.

Yammerknit refuses to overwrite a record

Keep the existing source and base artifact. Store the changed artifact as a revision, or create a distinct record when the source itself changed. The refusal is a custody safeguard.

A record changed, disappeared or moved

Preserve the damaged record. Restore the named missing or changed file only from a known matching backup, then inspect again. Do not regenerate expected hashes to bless changed bytes. Intentional new source material belongs in a new record; corrected derived content belongs in a revision.

Move the entire workspace: relative references need no manifest rewrite. For an unsupported older absolute-path record, retain its history and reconstruct a new record from known original evidence. If a revision fork or cycle appears, preserve all branches and reconcile in a copied workspace; never choose by timestamp alone.

A busy/interrupted error names the exact lock and process. Confirm no writer is running before removing only that stale lock. Staging is not selected as current. Linked or junction paths are unsupported; use the physical directory or an ordinary complete copy.

Still blocked? Ask in the Stunspot Prompting community and include the version, host, exact error, and failure stage. Remove private source content first.
