# Privacy

Yammerknit stores data only when the user or host chooses a workspace. Its core skill sends no telemetry and includes no cloud storage, embedding service, or vector database.

The optional YouTube subtitle helper invokes a separately installed `yt-dlp` and contacts YouTube for accessible subtitle data. It disables browser-cookie loading, playlist traversal, audiovisual download, and local `yt-dlp` configuration. It records the source URL and acquisition metadata inside the user-selected workspace.

Users control later transfer, embedding, backup, and publication of their sources and Yammerknits.

The agent host may process supplied content through its configured model/provider. User documents can contain private data even though the helper adds no credentials. Source-manifest hashes establish byte consistency, not authenticity or consent.
