# Description

Yammerknit turns documents and transcripts into source-grounded semantic extracts: useful claims, their relationships and the context that makes them trustworthy to reuse. It preserves original evidence separately from authored meshes, supports inspection and revisions, and keeps inference and proposed transfer distinct from source statements. A complete worked example shows how a confident-looking extraction can misread an observational result.

# Usage Notes

Copy the .zip from "Additional Files" to your Codex, Claude Code, or other harness, or add the .zip to a project knowledge base in Chat. Attach or reference the .zip in chat and say, "Install this Augment." The prompt in this post is optional.

- Supply a document or transcript and, when useful, the question you want to answer later.
- Use the included cooling-pilot example for a complete first task, source comparison and native record journey.
- Choose a workspace outside the installation to preserve sources, artifacts and revisions; browse it later without remembering an ID.
- Keep source qualifiers and locators with each reused chunk. Embedding, vector storage and measured retrieval performance belong to a separate pipeline.

[Public repository and documentation](https://github.com/Stunspot/yammerknit).
