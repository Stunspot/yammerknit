# Description

Yammerknit converts source documents and transcripts into structured semantic meshes for retrieval systems. Each mesh identifies concepts, relationships, and retrieval handles while retaining source identity and boundaries. It can create, inspect, organize, or minimally repair these artifacts before embedding or indexing, giving RAG builders a cleaner corpus without treating the derived mesh as a replacement for the original material.

# Usage Notes

Copy the .zip from "Additional Files" to your Codex, Claude Code, or other harness (or add the .zip file to a knowledge base of a project on Chat) and install the contained Augment Agent SKILL. The prompt this post contains has a clean install and onboarding process but is not required. Hit copy to clipboard and paste to your harness in chat with the .zip file.

- Bring one source document or transcript and tell it what the future retrieval system needs to find or answer.
- The result is a retrieval-ready semantic artifact, not a replacement for the original source or proof that every statement in it is true.
- Yammerknit prepares the mesh; embedding it, loading it into a vector database, and deploying a RAG system are separate steps.

Public GitHub Repo: [yammerknit](https://github.com/Stunspot/yammerknit)
