# Support

Yammerknit is supported through the Stunspot Prompting community:

- [Stunspot Prompting Discord](https://discord.gg/stunspot)
- [Stunspot](https://stunspot.com/)

When reporting a problem, include the Yammerknit version, host, installation state, exact error, and whether the failure concerns installation, transcript acquisition, artifact validation, or semantic quality. Remove private source content, credentials, and unrelated personal data before sharing logs or receipts.
