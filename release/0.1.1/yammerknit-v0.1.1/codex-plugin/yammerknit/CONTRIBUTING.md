# Contributing

Yammerknit accepts focused defect reports and proposed improvements through [GitHub Issues](https://github.com/Stunspot/yammerknit/issues). Use the [Stunspot Prompting Discord](https://discord.gg/stunspot) for usage questions that do not require a repository change.

When reporting a defect, include the version, host, installation state, exact command or request, observed output, expected behavior, and the smallest non-sensitive reproduction. Remove source material, credentials, tokens, cookies, and unrelated personal data.

Before proposing a change:

1. Preserve the canonical Yammerknit SOP, Rupert Giles persona, branding, provenance, and frozen release archives exactly unless the rights holder explicitly authorizes a governed revision.
2. Keep source evidence, normalized text, generated artifacts, revisions, and receipts distinct.
3. Update the customer journey and tests when behavior or supported-host instructions change.
4. Run the repository verification commands documented in `README.md` and report the exact results and untested boundaries.
5. Do not weaken collision refusal, source custody, subtitle-only acquisition boundaries, or literal vector-RAG claims to make a test pass.

A proposal is not accepted, merged, released, submitted to a marketplace, or published until the appropriate maintainer performs those actions.
