## Try the native record journey

From this complete skill folder, use Python 3.10 or later. Use PowerShell on Windows or a terminal shell on macOS/Linux. The example uses `$HOME/YammerknitPractice`, outside the installation; retain this skill-folder working directory for source and script paths. Each command is one line and works in PowerShell or a typical terminal.

```text
python scripts/yammerknit_tool.py init-record --source examples/pilot-source.txt --workspace "$HOME/YammerknitPractice" --channel "Fictional Workshop" --title "Cooling checklist pilot"
python scripts/yammerknit_tool.py inspect-record --workspace "$HOME/YammerknitPractice"
```

Copy the returned `record_id` exactly as ID in the next commands. Inspection first shows `current: null`: preserving a source has not created an artifact.

```text

python scripts/yammerknit_tool.py inspect-record --workspace "$HOME/YammerknitPractice" --record-id "ID"
```

Expect a structural pass, a saved base artifact and `health: verified-present-bytes`. Read the source comparison above before treating it as reviewed content. The helper cannot perform that semantic judgment.
